01 / CONCEPT

東方文化的重新建構

我不希望刺青只是風格模仿。

對我來說， 刺青更像是一種文化語言。

我嘗試將東方工筆、重彩、 寺院空間、傳統紋樣與現代構圖重新結合， 建立屬於自己的視覺系統。

這不是復古， 而是在重新理解東方美學之後， 對當代刺青的一次重新建構。
I never wanted tattoo to become style imitation.

For me, tattoo is a cultural language.

I combine Eastern fine-line painting, heavy color composition, traditional patterns, temple spatial aesthetics and contemporary structures to build my own visual system.

This is not nostalgia, but a reconstruction of Eastern aesthetics within contemporary tattoo culture.
02 / VISUAL SYSTEM

東方千禧風

東方千禧風並不是單一風格。

它建立在東方文化的空間感、 重彩秩序與工筆線條之上， 同時融入當代刺青的視覺張力。

我希望它既保留東方氣質， 又能成為屬於這個時代的新視覺語言。
Oriental Millennium is not a single style.

It is built upon Eastern spatial aesthetics, heavy color structures and fine-line systems, while integrating contemporary visual tension.

I hope it preserves Eastern identity while becoming a new visual language for the current era.
